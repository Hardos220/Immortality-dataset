**Открытая база данных об отношении людей к продлению жизни, бессмертию, долголетию
и здоровому образу жизни.** 185 источников, 2 404 числовых показателя, замеры по 109 странам
и межстрановые исследования охватом до 183 стран. Замеры установок — 1973–2026,
демографические ряды начинаются с 1751 года.

К данным приложена интерактивная витрина с 37 авторскими графиками, на русском
и английском языках:

**[открыть витрину →](https://hardos220.github.io/Immortality-dataset/)**

Файл `index.html` самодостаточный: ни одной внешней зависимости, работает
из локальной папки и офлайн.

## Зачем это

Общественное мнение о продлении жизни измеряют десятки лет, но результаты
несопоставимы между собой. Один и тот же вопрос, заданный по-разному, даёт в США
от 19 % до 77 % согласия. Национальные опросы используют разные пороги («жить вечно»,
«дожить до 100», «до 120 при здоровье»), разные форматы ответа и разные допущения
о здоровье. Гармонизированного международного инструмента не существует.

Эта база — попытка свести разрозненные замеры в одну прослеживаемую таблицу,
показать, где данные сопоставимы, а где нет, и обозначить пустые места на карте.
**Это агрегатор, а не первоисточник:** каждая строка ведёт к исходной публикации.

### Главный результат

Показатель «сколько людей хотят жить дольше» падает **всемеро** в зависимости
от того, что именно мы измеряем:

| Что измеряем | Значение | Источник |
|---|---|---|
| «Долго жить — это хорошо» (ценность) | 69,7 % | Япония, N = 19 800 |
| «Хочу жить вечно» (желание) | 37,4 % | 25 стран, N = 14 000 |
| Пересадка мозга в клон приемлема (намерение) | 30 % | Россия, N = 1 600 |
| Допускаю крионику для себя (допущение) | 22 % | Германия, N = 1 000 |
| «Принял бы рапамицин» (конкретное средство) | 10 % | Нидерланды, N = 178 |
| ЗОЖ по пяти критериям (измеренное поведение) | 9,7 % | Россия, 60 тыс. домохозяйств |

Основной обвал приходится не на конец шкалы, а на её начало: между ценностным
суждением и «хочу жить вечно» доля падает почти вдвое при первом же ужесточении
формулировки, которое ещё ничего не стоит респонденту.

Самая чистая проверка этого разрыва — не между людьми, а **внутри одного человека**.
В NHANES физическую активность измерили у одних и тех же 3 370 участников дважды:
по анкете норме соответствуют **23 %**, по акселерометру — **0,3 %**.

Та же закономерность воспроизводится **внутри одной страны** — см. российскую лестницу
на вкладке «Лестница» витрины.

Из скриптов набора самостоятельно работает `validate.py` — он проверяет
именно те CSV, которые вы скачали:

```
python scripts/validate.py
```

Остальные три описывают, как набор получен, и требуют рабочих файлов
проекта, которых в наборе нет. При запуске из набора они это объясняют
и завершаются без ошибки.

Каждая опубликованная версия витрины сохраняется целиком в архиве рабочего
репозитория, с манифестом и SHA-256; в этот набор архив не входит. Сейчас
там 58 версий. Три группы в архив не попали: 0.1–0.3 (до появления
механизма), 0.55–0.86 и 0.93–0.103.

`CHANGELOG.md` ведёт историю до версии 0.53 и затем сразу к выпуску 1.0;
записи за промежуточные предрелизные версии не велись, и восстанавливать их
задним числом я не стал. Всё, что нумеровалось как 0.x, наружу не выходило.

## Форматы

Файлы без суффикса — **международный формат**: разделитель запятая, десятичная точка,
UTF-8 с BOM. Открываются напрямую:

```python
import pandas as pd
df = pd.read_csv("data/findings.csv")
```

```r
df <- read.csv("data/findings.csv", encoding = "UTF-8")
```

Файлы с суффиксом `_ru` — для русской локали Excel: разделитель `;`, десятичная запятая.

## Быстрый старт

```python
import pandas as pd

df = pd.read_csv("data/findings.csv")

# сколько людей заявляют, что хотят жить вечно, по странам
df[df.indicator == "want_live_forever"][
    ["country_en", "year_start", "value_min", "n_sample", "source_name"]
]

# всё по России
df[df.country_iso3 == "RUS"]

# только репрезентативные источники
df[df.source_tier == "T1"]
```

## Перед тем как использовать числа

Три правила, без которых данные легко исказить. Подробно — в
[`data/codebook.md`](data/codebook.md).

1. **Проценты из разных строк не складываются и часто не сравниваются.**
   Сопоставимы только показатели с одинаковым значением поля `indicator`.
   «Хотите жить вечно» и «хотите дожить до 100» — разные конструкты, а не разные
   оценки одной величины.

2. **Всегда переносите вместе с цифрой поля `n_sample`, `year_start` и `source_name`.**
   Число без объёма выборки и года не значит ничего.

3. **Следите за полем `value_type`.** Значение `range` означает, что первоисточник
   дал диапазон (`value_min`–`value_max`), а не точечную оценку; `lower_bound` —
   что известна только нижняя граница.

Отдельно: строки с `source_tier = T3` получены на неслучайных выборках
и не обобщаются на население.
